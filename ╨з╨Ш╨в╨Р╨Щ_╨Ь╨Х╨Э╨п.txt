НОУТМАРКЕТ: ВСЁ В ОДНОМ АРХИВЕ
==============================
Сайт магазина ноутбуков и ПК (Бишкек, цены в сомах) + SQL-база + Python-сервер + админка.

СТРАНИЦЫ (папка static/)
  index.html    главная: 3D-ноутбук ASUS ROG
  catalog.html  каталог 50 ноутбуков: фильтры, сравнение, отзывы, корзина, 3D
  pc.html       25 системных блоков: 3D-разбор, цены комплектующих, работа мастера
  admin.html    админка (цены, остатки, заказы, статистика), открывается через сервер

БЫСТРЫЙ ПРОСМОТР БЕЗ СЕРВЕРА
  Распакуйте архив и откройте любой html из папки static. Страницы самодостаточные.
  Ссылки между страницами, заказы, отзывы и живые остатки работают только через сервер.

ПОЛНЫЙ ЗАПУСК С БАЗОЙ
  1) Установите Python 3.8+
  2) В папке NoutMarket:  python server.py      (Linux/macOS: python3 server.py)
     Пароль админки: переменная ADMIN_PASSWORD (по умолчанию admin123, обязательно смените)
  3) Откройте http://localhost:8000  (каталог /catalog, ПК /pc, админка /admin)
  Подробнее: README.txt и ДОКУМЕНТАЦИЯ.md (архитектура, схема БД, API) для отчёта.

ФАЙЛЫ
  server.py, manage.py        сервер и управление базой из консоли
  laptop_store.sql            схема и данные БД (ноутбуки, заказы, отзывы, ПК)
  products.csv                каталог ноутбуков для Access/Excel
  static/config.js            ваши контакты (WhatsApp, Telegram, телефон)
  tools/gen_pc_data.py        генератор данных ПК (курс 87,45 сом/$, цены США 2026)

СВОЙ НОМЕР ДЛЯ ЗАКАЗОВ (WhatsApp / Telegram / телефон)
  python set_contacts.py 996700123456 мой_ник "+996 700 12-34-56"
  (номер WhatsApp цифрами без плюса, ник Telegram без @). Скрипт меняет контакты сразу во всех страницах.
  Вручную: в файлах static/index.html, catalog.html, pc.html и config.js найдите 996555000000 и your_shop.

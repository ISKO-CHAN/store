НОУТМАРКЕТ: сайт + SQL-база + Python
====================================
Нужен только Python 3.8+ (ничего устанавливать не надо).

ЗАПУСК
  Windows (PowerShell):  $env:ADMIN_PASSWORD="мой_пароль"; python server.py
  Linux / macOS:         ADMIN_PASSWORD=мой_пароль python3 server.py
  Главная (3D-история): http://localhost:8000   Каталог: http://localhost:8000/catalog   Админка: http://localhost:8000/admin
  Порт можно сменить: PORT=8080. База shop.db создаётся сама из laptop_store.sql.

КАК МЕНЯТЬ ТОВАРЫ, ЦЕНЫ И ОСТАТКИ
  1) Админка /admin: правите цену, остаток по каждому магазину, фото; добавляете и удаляете товары;
     на вкладке «Заказы» меняете статус (при отмене товар возвращается на склад).
  2) SQL напрямую: откройте shop.db в «DB Browser for SQLite» и выполняйте, например:
        UPDATE products SET price_kgs = 45900 WHERE id = 5;
        UPDATE stock SET qty = 10 WHERE product_id = 5 AND store_id = 1;
     Сайт подхватит изменения сам (обновляется каждые 15 секунд).
  3) Python-скрипт:
        python manage.py list asus
        python manage.py price 5 45900
        python manage.py stock 5 1 10          (товар 5, магазин 1, остаток 10)
        python manage.py import products.csv   (каталог из Access: файл products.csv)
        python manage.py sql "SELECT * FROM v_catalog WHERE in_stock = 0"

ФОТО
  Положите файлы в static/img/ и впишите в админке путь вида /img/ideapad1.jpg.
  Сайт сразу покажет фото вместо рисунка.

БЕЗОПАСНОСТЬ
  - Обязательно задайте свой ADMIN_PASSWORD.
  - Чтобы сайт был доступен из интернета, запустите его на сервере (VPS) за HTTPS
    (например, nginx или Caddy). Для 3D и шрифтов посетителям нужен интернет (CDN).
  - Делайте копию shop.db.

НОВОЕ В ЭТОЙ ВЕРСИИ
  - Заказ в WhatsApp / Telegram: впишите свои контакты в static/config.js.
  - Уведомления о заказах в Telegram: задайте TG_TOKEN (токен бота от @BotFather) и TG_CHAT (id чата).
  - Статистика, резервные копии (папка backups/, раз в сутки и при запуске), выгрузка заказов в CSV: вкладки админки.
  - Отзывы, сравнение моделей, избранное, подбор по задаче, рассрочка, контакты, установка как приложение (PWA).
Описание архитектуры для отчёта: ДОКУМЕНТАЦИЯ.md

3D-МОДЕЛЬ ASUS ROG
  Главная страница показывает только игровой ноутбук ASUS ROG. Эта же модель используется в окне товара для всех ноутбуков ASUS.
  Файлы: static/rog_model.js (модель GLB в base64), static/rog3d.js (просмотр), static/vendor/ (three.js и GLTFLoader, интернет не нужен).
  Модель взята из присланного архива 16-asus-laptop.rar (Blender, 2020). Перед публикацией проверьте лицензию и автора модели.

СТРАНИЦА 3: ПК (pc.html, адрес /pc)
  25 готовых системных блоков. Клик по ПК открывает окно: 3D-сборка разбирается на детали, справа цены комплектующих,
  внизу блок «Работа мастера» и итог под ключ. Цены в сомах: комплектующие по ценам рынка США 2026 г., курс НБКР 87,45 сом за $1.
  Данные ПК встроены в страницу и лежат в базе (таблицы pc_builds, pc_parts, представление v_pc в laptop_store.sql).
